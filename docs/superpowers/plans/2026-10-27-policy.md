# Policy (Step 15b-1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kyverno in Audit with the restricted Pod Security policies, pinned images and allowed registries. A `policy`
basic check blocks violations in CI. Every fixable workload is fixed, every inherent one has a written exception, and
PSA baseline is the second layer.

**Architecture:**
- `system/kyverno` wraps the `kyverno` and `kyverno-policies` charts (3.9.2) and adds two custom `ValidatingPolicy`
  objects.
- `scripts/check-policy` runs the `kyverno` CLI on every render.
- Exceptions are `PolicyException`s in the excused component's own chart or app file.

**Tech Stack:** Kyverno 1.19.2 (CEL `ValidatingPolicy`), Helm, POSIX sh, Go tests.

**Spec:** `docs/superpowers/specs/2026-10-27-policy-design.md`

## Global Constraints

- Charts `kyverno` 3.9.2 and `kyverno-policies` 3.9.2. The `kyverno` CLI 1.19.2 comes from `unstable`, since
  nixos-26.05 ships 1.18.2.
- The policies are Audit in the cluster, and the check fails CI on any `fail` or `error`.
- `podSecurityUserNamespaces: true`, for Woodpecker's step pods.
- Every `PolicyException` names its policies and its workloads, and gives its reason in an annotation.
- Kyverno's pods carry `istio.io/dataplane-mode: none` (the API server calls them), and its webhooks use
  `failurePolicy: Ignore`.
- Mesh and egress rules still hold: `scripts/check-mesh-policies` and `scripts/check-env-config` pass.
- `scripts/ci-check all`, lint and gofmt pass before every commit.

## Review Focus

1. **A fix that breaks an app.** A securityContext an image cannot run under (it writes to `/`, or needs root) must
   not ship. Test: the sandbox suite (`make dev` full) passes.
2. **An exception broader than its workload**, such as a whole namespace or every policy. Test: `TestCheckPolicy`
   fails when the exceptions file is dropped. A review reads each exception's match conditions.
3. **Kyverno down or slow at admission** must not block deploys while in Audit (`failurePolicy: Ignore`). Test:
   `TestPolicy` checks the webhook configuration's `failurePolicy`.
4. **The PSA label on a namespace that needs `privileged`**, set too strictly, would stop its pods on any restart.
   Test: the sandbox suite (TestNodeRestart restarts every pod).
