# OpenTofu State on R2 with Encryption Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Production's OpenTofu state lives in the R2 bucket `homelab-production-tfstate`, every environment's state is encrypted with a passphrase that a tested script can rotate, and Cloudflare credentials come from `cf auth login`.

**Architecture:**
- `infra/root.hcl` generates two files for every unit:
  - `backend.tf`: production gets the `http` backend on R2's object API with `cf`'s OAuth token; the sandbox keeps local state.
  - `encryption.tf`: pbkdf2 and aes_gcm. A fallback appears only for a rotation (the previous passphrase) or a migration (unencrypted).
- Three small POSIX scripts, each tested offline against fake commands or a throwaway Terragrunt tree:
  - `scripts/cloudflare-credentials`: account and token;
  - `scripts/ensure-state-bucket`: creates the bucket;
  - `scripts/rotate-state-passphrase`: re-encrypts every unit's state.
- `cf` is built in `flake.nix` from nixpkgs PR #569193's derivation.

**Tech Stack:** OpenTofu 1.11 (state encryption, `http` backend), Terragrunt 1.1, Nix (`stdenv.mkDerivation` with pnpm), POSIX `sh`, `curl` and `jq`, Go tests.

**Spec:** `docs/superpowers/specs/2026-10-18-state-r2-design.md`

## Global Constraints

- Bucket `homelab-production-tfstate`; object `<unit>/tfstate.json`; address `https://api.cloudflare.com/client/v4/accounts/<account>/r2/buckets/<bucket>/objects/<unit>/tfstate.json`; `update_method = "PUT"`; header `Authorization: Bearer <token>`; no lock.
- Only production uses R2 and `cf`. Sandbox units never call `cf`, and `make dev` needs no Cloudflare login.
- Encryption in every environment: `key_provider "pbkdf2"`, `method "aes_gcm"`, applied to `state` and `plan`, `enforced = true`.
- Passphrase: `HOMELAB_STATE_PASSPHRASE` from `~/.config/homelab/state.env` (mode 600, loaded by `.envrc`), handed to OpenTofu only as `TF_VAR_state_passphrase`.
  - Never print it, log it, write it to a generated file, or commit it. Claude never reads `state.env`.
  - The user creates the file and keeps a copy in a password manager.
- `cf` pinned at `cf@1.0.0-beta.18` (only betas exist).
- `~/.config/homelab/cloudflare.env` and its `.envrc` line are removed.
- Production migration happens only after the user ran `! cf auth login` and confirmed. The local `.state/production/` files stay until the user deletes them.
- No test name contains a word of `make dev`'s main filter (`Smoke|Identity|SSO|Gateway|Forgejo|Mesh|Monitoring|Egress|Secrets|Ntfy|Logs`) or `NodeRestart`.
- Commits end with the session's attribution lines. Never commit to `dev` or `master`.

## Review Focus

1. **`make -C infra check` and `terragrunt hcl validate` without a passphrase:** parsing `root.hcl` must not fail. Only commands that touch state may refuse. The check is pinned in Task 3, Step 7, which runs `make -C infra check` with the variable unset.
2. **The OAuth token in generated files:** `backend.tf` in `.terragrunt-cache` carries the Bearer token, as upstream's does. `.terragrunt-cache/` must stay git-ignored and user-only. Task 4, Step 6 checks `git check-ignore` and the permissions hook.
3. **A unit with no state** (production `argocd`, `openbao` and `secrets` today): rotation must skip it rather than push an empty state. Pinned by `TestStatePassphraseRotation/empty_unit_skipped`.
4. **`init -reconfigure` against `-migrate-state`:** the two flags conflict. A migration run must not get `-reconfigure`. Task 4's `HOMELAB_STATE_MIGRATE` switch covers it, and Task 5 uses it.
5. **A failed rotation halfway:** every unit is pulled before anything is pushed, so a pull failure changes nothing. Pinned by `TestStatePassphraseRotation/wrong_previous_changes_nothing`.

```go
// fakeBin writes executable scripts into a temporary directory placed first on PATH.
func fakeBin(t *testing.T, scripts map[string]string) (dir string, env []string) {
	dir = t.TempDir()
	for name, body := range scripts {
		require.NoError(t, os.WriteFile(filepath.Join(dir, name), []byte("#!/bin/sh\n"+body), 0o755))
	}
	return dir, append(os.Environ(), "PATH="+dir+":"+os.Getenv("PATH"), "FIXTURES="+dir)
}

func runScript(t *testing.T, env []string, script string, args ...string) (string, error) {
	cmd := exec.Command("sh", append([]string{"../scripts/" + script}, args...)...)
	cmd.Env = env
	out, err := cmd.CombinedOutput()
	return strings.TrimSpace(string(out)), err
}
```

```sh
#!/bin/sh
# Prints {"account_id": ..., "token": ...} for OpenTofu (infra/root.hcl): production's from cf's OAuth login
# (`cf auth login`), empty strings for every other environment, which never talks to Cloudflare.
# CLOUDFLARE_ACCOUNT_ID picks the account when the login sees several.
set -eu
env=${1:?usage: cloudflare-credentials <env>}
if [ "$env" != production ]; then
	echo '{"account_id":"","token":""}'
	exit
fi
identity=$(env -u CLOUDFLARE_API_TOKEN -u CLOUDFLARE_API_KEY -u CLOUDFLARE_EMAIL CF_SEND_TELEMETRY=false cf --quiet auth whoami)
token_file=$(printf '%s' "$identity" | jq -r '.authSource | sub("^OAuth token from "; "")')
account=${CLOUDFLARE_ACCOUNT_ID:-$(printf '%s' "$identity" | jq -r '.accounts[0].id')}
jq -cn --arg account "$account" --slurpfile token "$token_file" '{account_id: $account, token: $token[0].oauth_token}'
```

- [ ] **Step 4: Write `scripts/ensure-state-bucket`**

```sh
#!/bin/sh
# Creates production's OpenTofu state bucket on R2 when it does not exist (a before_hook of `init`, infra/root.hcl).
# The token goes to curl through a header file, never its command line.
set -eu
bucket=${1:?usage: ensure-state-bucket <bucket>}
credentials=$("${CLOUDFLARE_CREDENTIALS:-$(dirname "$0")/cloudflare-credentials}" production)
account=$(printf '%s' "$credentials" | jq -r .account_id)
work=$(mktemp -d)
trap 'rm -rf "$work"' EXIT
(umask 077; printf '%s' "$credentials" | jq -r '"Authorization: Bearer " + .token' > "$work/auth")
api="https://api.cloudflare.com/client/v4/accounts/$account/r2/buckets"

code=$(curl -sS -H "@$work/auth" -o "$work/body" -w '%{http_code}' "$api/$bucket")
case $code in
	200) exit ;;
	404) ;;
	*) echo "ensure-state-bucket: GET $bucket: HTTP $code: $(jq -r '[.errors[].message] | join("; ")' "$work/body" 2>/dev/null)" >&2; exit 1 ;;
esac
code=$(curl -sS -X POST -H "@$work/auth" -H 'Content-Type: application/json' -d "{\"name\":\"$bucket\"}" -o "$work/body" -w '%{http_code}' "$api")
if [ "$code" != 200 ]; then
	echo "ensure-state-bucket: create $bucket: HTTP $code: $(jq -r '[.errors[].message] | join("; ")' "$work/body" 2>/dev/null)" >&2
	exit 1
fi
echo "ensure-state-bucket: created $bucket"
```

```go
package test

import (
	"os"
	"os/exec"
	"path/filepath"
	"strings"
	"testing"

	"github.com/stretchr/testify/assert"
	"github.com/stretchr/testify/require"
)

const (
	passphraseA = "passphrase-a-0123456789"
	passphraseB = "passphrase-b-9876543210"
)

// stateTree builds a throwaway repository with this repository's infra/root.hcl and scripts, and two sandbox units:
// "marker" (a terraform_data resource, no provider) and "empty" (no resources).
func stateTree(t *testing.T) string {
	root := t.TempDir()
	mustWrite := func(path, body string, mode os.FileMode) {
		require.NoError(t, os.MkdirAll(filepath.Dir(filepath.Join(root, path)), 0o755))
		require.NoError(t, os.WriteFile(filepath.Join(root, path), []byte(body), mode))
	}
	for _, f := range []string{"infra/root.hcl", "scripts/rotate-state-passphrase", "scripts/cloudflare-credentials"} {
		body, err := os.ReadFile(filepath.Join("..", f))
		require.NoError(t, err)
		mustWrite(f, string(body), 0o755)
	}
	mustWrite("infra/_modules/marker/main.tf", `resource "terraform_data" "marker" { input = "visible-marker" }`+"\n", 0o644)
	mustWrite("infra/_modules/empty/main.tf", "\n", 0o644)
	for _, unit := range []string{"marker", "empty"} {
		mustWrite("infra/sandbox/"+unit+"/terragrunt.hcl", `include "root" {
  path = find_in_parent_folders("root.hcl")
}
terraform {
  source = "${find_in_parent_folders("_modules")}//`+unit+`"
}
`, 0o644)
	}
	require.NoError(t, exec.Command("git", "-C", root, "init", "-q").Run())
	return root
}

// tg runs terragrunt in a unit with the given passphrases ("" leaves a variable unset).
func tg(t *testing.T, root, unit, current, previous string, args ...string) (string, error) {
	cmd := exec.Command("terragrunt", append(args, "--non-interactive", "--log-level", "error")...)
	cmd.Dir = filepath.Join(root, "infra/sandbox", unit)
	cmd.Env = stateEnv(current, previous)
	out, err := cmd.CombinedOutput()
	return string(out), err
}

func stateEnv(current, previous string) []string {
	var env []string
	for _, e := range os.Environ() {
		if !strings.HasPrefix(e, "HOMELAB_STATE_") && !strings.HasPrefix(e, "TF_VAR_") {
			env = append(env, e)
		}
	}
	if current != "" {
		env = append(env, "HOMELAB_STATE_PASSPHRASE="+current)
	}
	if previous != "" {
		env = append(env, "HOMELAB_STATE_PASSPHRASE_PREVIOUS="+previous)
	}
	return env
}

func rotate(t *testing.T, root, current, previous string) (string, error) {
	cmd := exec.Command("sh", "scripts/rotate-state-passphrase", "sandbox")
	cmd.Dir = root
	cmd.Env = stateEnv(current, previous)
	out, err := cmd.CombinedOutput()
	return string(out), err
}

func stateFile(t *testing.T, root, unit string) string {
	body, _ := os.ReadFile(filepath.Join(root, ".state/sandbox", unit, "terraform.tfstate"))
	return string(body)
}

func TestStatePassphraseRotation(t *testing.T) {
	root := stateTree(t)
	out, err := tg(t, root, "marker", passphraseA, "", "apply", "-auto-approve")
	require.NoError(t, err, out)
	_, err = tg(t, root, "empty", passphraseA, "", "apply", "-auto-approve")
	require.NoError(t, err)

	t.Run("state encrypted at rest", func(t *testing.T) {
		state := stateFile(t, root, "marker")
		assert.Contains(t, state, "encrypted_data")
		assert.NotContains(t, state, "visible-marker")
	})

	t.Run("refusals change nothing", func(t *testing.T) {
		before := stateFile(t, root, "marker")
		for _, c := range []struct{ name, current, previous string }{
			{"no previous", passphraseB, ""},
			{"no current", "", passphraseA},
			{"equal", passphraseA, passphraseA},
			{"too short", "short", passphraseA},
		} {
			out, err := rotate(t, root, c.current, c.previous)
			assert.Error(t, err, "%s: %s", c.name, out)
			assert.NotContains(t, out, passphraseA, "a passphrase was printed")
		}
		assert.Equal(t, before, stateFile(t, root, "marker"))
	})

	t.Run("wrong previous changes nothing", func(t *testing.T) {
		before := stateFile(t, root, "marker")
		out, err := rotate(t, root, passphraseB, "wrong-passphrase-000000")
		assert.Error(t, err, out)
		assert.Equal(t, before, stateFile(t, root, "marker"))
	})

	t.Run("rotated", func(t *testing.T) {
		out, err := rotate(t, root, passphraseB, passphraseA)
		require.NoError(t, err, out)
		assert.NotContains(t, out, passphraseA)
		assert.NotContains(t, out, passphraseB)
		pulled, err := tg(t, root, "marker", passphraseB, "", "state", "pull")
		require.NoError(t, err, pulled)
		assert.Contains(t, pulled, "visible-marker")
		_, err = tg(t, root, "marker", passphraseA, "", "state", "pull")
		assert.Error(t, err, "the old passphrase still reads the state")
	})

	t.Run("empty unit skipped", func(t *testing.T) {
		_, err := tg(t, root, "empty", passphraseB, "", "state", "pull")
		assert.NoError(t, err)
	})
}
```

```hcl
generate "encryption" {
  path      = "encryption.tf"
  if_exists = "overwrite_terragrunt"
  contents  = <<-EOF
    variable "state_passphrase" {
      type      = string
      sensitive = true
    }
    %{~if local.state_passphrase_previous != ""}
    variable "state_passphrase_previous" {
      type      = string
      sensitive = true
    }
    %{~endif}
    terraform {
      encryption {
        key_provider "pbkdf2" "current" {
          passphrase = var.state_passphrase
        }
        method "aes_gcm" "current" {
          keys = key_provider.pbkdf2.current
        }
        %{~if local.state_passphrase_previous != ""}
        key_provider "pbkdf2" "previous" {
          passphrase = var.state_passphrase_previous
        }
        method "aes_gcm" "previous" {
          keys = key_provider.pbkdf2.previous
        }
        %{~endif}
        %{~if local.state_migrate}
        method "unencrypted" "migrate" {}
        %{~endif}
        state {
```

- [ ] **Step 7: Write `scripts/rotate-state-passphrase`**

```sh
#!/bin/sh
# Re-encrypts every OpenTofu state of an environment with a new passphrase (docs/installation/production/external-resources.md):
# put the new passphrase in HOMELAB_STATE_PASSPHRASE and the old one in HOMELAB_STATE_PASSPHRASE_PREVIOUS, run this,
# then update the password manager and ~/.config/homelab/state.env and drop _PREVIOUS. Every state is pulled before
# any is pushed, so a wrong old passphrase changes nothing. Passphrases are never printed.
set -eu
env=${1:?usage: rotate-state-passphrase <env>}
: "${HOMELAB_STATE_PASSPHRASE:?set HOMELAB_STATE_PASSPHRASE to the new passphrase}"
: "${HOMELAB_STATE_PASSPHRASE_PREVIOUS:?set HOMELAB_STATE_PASSPHRASE_PREVIOUS to the old passphrase}"
if [ "$HOMELAB_STATE_PASSPHRASE" = "$HOMELAB_STATE_PASSPHRASE_PREVIOUS" ]; then
	echo "rotate-state-passphrase: the new passphrase equals the old one" >&2
	exit 1
fi
if [ ${#HOMELAB_STATE_PASSPHRASE} -lt 16 ]; then
	echo "rotate-state-passphrase: the new passphrase is shorter than 16 characters" >&2
	exit 1
fi
root=$(git rev-parse --show-toplevel)
work=$(mktemp -d)
chmod 700 "$work"
trap 'rm -rf "$work"' EXIT
tg() { terragrunt --non-interactive --log-level error "$@"; }

units=
for dir in "$root"/infra/"$env"/*/; do
	[ -f "$dir/terragrunt.hcl" ] || continue
	unit=$(basename "$dir")
	(cd "$dir" && tg state pull) > "$work/$unit.json" || { echo "rotate-state-passphrase: cannot read $env/$unit with the old passphrase; nothing changed" >&2; exit 1; }
	if [ -s "$work/$unit.json" ]; then
		units="$units $unit"
	else
		echo "$env/$unit: no state, skipped"
	fi
done
for unit in $units; do
	(cd "$root/infra/$env/$unit" && tg state push -force "$work/$unit.json")
	echo "$env/$unit: re-encrypted"
done
for unit in $units; do
	(cd "$root/infra/$env/$unit" && HOMELAB_STATE_PASSPHRASE_PREVIOUS= tg state pull >/dev/null) || { echo "rotate-state-passphrase: $env/$unit does not read with the new passphrase alone" >&2; exit 1; }
done
echo "Done. Update the password manager and ~/.config/homelab/state.env with the new passphrase, then unset HOMELAB_STATE_PASSPHRASE_PREVIOUS."
```
