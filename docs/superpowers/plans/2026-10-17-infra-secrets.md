# Step 8b: OpenTofu's secrets through External Secrets, self-hosted ntfy — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cloudflare's, WireGuard's and Tailscale's secrets reach OpenBao as Kubernetes Secrets OpenTofu writes and a
`PushSecret` pushes; alerts go to a self-hosted ntfy published through the Tunnel; `external/` and `scripts/backup`
disappear.

**Architecture:** A new OpenTofu unit `infra/<env>/secrets` applies Secrets into namespace `infra-secrets`; the new
component `platform/infra-secrets` pushes them through `SecretStore` `openbao-infra` (OpenBao role/policy `infra`: every
branch except `generated/`). `apps/ntfy.yaml` runs ntfy (users and tokens generated by `platform/global-secrets`);
Alertmanager posts to it directly.

**Tech Stack:** OpenTofu + Terragrunt (providers hashicorp/random 3.9.1, OJFord/wireguard 0.4.1+2), OpenBao 2.7.1,
External Secrets 2.12 (`PushSecret` v1alpha1), ntfy v2.31.1, kube-prometheus-stack, app-template, Go tests (terratest).

**Spec:** `docs/superpowers/specs/2026-10-17-infra-secrets-design.md`

## Global Constraints

- Feature branch `feat/infra-secrets` (exists, from `dev`); PR into `dev`. Never commit to `dev` or `master`.
- Versions pinned exactly: ntfy `v2.31.1`, `OJFord/wireguard` `0.4.1+2`, `hashicorp/random` `3.9.1`.
- Charts and app files hold no domain or IP: hosts as `<host>.{{ .Values.global.baseDomain }}`.
- A component's `ExternalSecret`s read `SecretStore` `openbao` with keys under its own namespace.
- Generated secrets: `<namespace>/generated/<name>`, pushed only by `platform/global-secrets` through `openbao-writer`.
  OpenTofu's: outside `generated/`, pushed only by `platform/infra-secrets` through `openbao-infra`.
- OpenBao's roles accept only audience `openbao`.
- Secret values never reach an argument, a log or the repo; never print them in a shell.
- Every meshed namespace needs an `AuthorizationPolicy` `allow`; in-cluster calls the renders cannot show go to `EXTRA`
  in `scripts/check-mesh-policies`.
- Basic checks before `make dev`: `scripts/render-chart <dir>` and `scripts/render-chart <dir> dev` for every changed
  chart or app file; `cd test && go vet ./... && go test -run 'TestSmokeAppsForEnv|TestIdentity(TOTPWaitsForNextStep|PKCE)|TestGatewayRouteReady|TestGatewayNodeAddressFromInspect' ./...`;
  `mkdocs build --strict`; `scripts/check-mesh-policies`; `scripts/check-env-config`; `scripts/check-secret-stores`;
  `make -C infra check`. Tools run through `direnv exec /home/nixos/homelab …`.
- Sandbox tests run once, at the end (`make dev-clean && make dev`), because OpenBao only loads policies on first start.

## Review Focus

1. A `PushSecret` whose source Secret does not exist in that environment (sandbox: no Cloudflare) must not exist:
   `values-dev.yaml` of `platform/infra-secrets` lists only `wireguard/private-key` (Task 1 render check).
2. ntfy reachable without credentials would leak every alert publicly: anonymous publish and subscribe must be
   refused (Task 4 test `TestNtfyDeniesAnonymous`).
3. The `infra` policy must not reach `generated/` even with `update` on `secret/data/*` (`deny` wins): Task 1 test
   `TestSecretsInfraRole` writes outside and is refused inside.
4. Re-running `make dev` (second apply of the unit) must keep the WireGuard key: Task 2 test
   `TestSecretsInfraPush` compares the pushed value with the Secret, and the module has no trigger on the key.
5. Alertmanager's token file must reach ntfy: an alert posted to Alertmanager arrives in topic `alerts` (Task 5 test
   `TestNtfyAlertmanagerDelivers`).

func TestSecretsInfraRole(t *testing.T) {
	secretsSandboxOnly(t)
	waitForUnsealed(t)

	defer admin(t, "kv", "metadata", "delete", "secret/grafana/infra-probe")
	out, err := bao(t, "infra", "infra-secrets", "openbao-infra", "kv", "put", "secret/grafana/infra-probe", "value=x")

	for _, args := range [][]string{
		{"kv", "get", "secret/grafana/generated/admin"},
		{"kv", "put", "secret/grafana/generated/admin", "password=x"},
		{"kv", "put", "secret/grafana/generated/new", "value=x"},
		{"kv", "metadata", "get", "secret/grafana/generated/admin"},
	} {
		out, err := bao(t, "infra", "infra-secrets", "openbao-infra", args...)
		assert.Error(t, err, "infra: bao %v", args)
		assert.Contains(t, out, "permission denied", "infra: bao %v", args)
	}
	out, err = bao(t, "infra", "grafana", "default", "kv", "get", "secret/grafana/infra-probe")
	assert.Error(t, err, "grafana logged in as infra")
	assert.Contains(t, out, "not authorized")
}

// OpenTofu's WireGuard key (infra/sandbox/secrets) reaches OpenBao through platform/infra-secrets, and comes back after
// its OpenBao value is lost
func TestSecretsInfraPush(t *testing.T) {
	secretsSandboxOnly(t)
	waitForUnsealed(t)
	want := secretValue(t, "infra-secrets", "wireguard.private-key", "private-key")
	require.NotEmpty(t, want)
	// The sandbox has no namespace wireguard (production only): read with the admin role
	read := func() string {
		out, err := bao(t, "admin", "openbao", "openbao-admin", "kv", "get", "-field=private-key", "secret/wireguard/private-key")
		if err != nil {
			return ""
		}
		return out
	}
	require.Eventually(t, func() bool { return read() == want }, 20*time.Minute, 15*time.Second,
		"secret/wireguard/private-key does not hold the Secret's value")

	admin(t, "kv", "metadata", "delete", "secret/wireguard/private-key")
	k8s.RunKubectl(t, k8s.NewKubectlOptions("", "", "infra-secrets"), "annotate", "pushsecret", "wireguard.private-key",
		"force-sync="+fmt.Sprint(time.Now().UnixNano()), "--overwrite")
	assert.Eventually(t, func() bool { return read() == want }, 5*time.Minute, 10*time.Second,
		"the lost value was not pushed again")
}

`infra/_modules/secrets/main.tf`:

```hcl
# Secrets OpenTofu creates or receives, written as Kubernetes Secrets into namespace infra-secrets, from where
# platform/infra-secrets pushes them to OpenBao (secret/<namespace>/<name>)
terraform {
  required_version = ">= 1.13"
  required_providers {
    wireguard = {
      source  = "OJFord/wireguard"
      version = "0.4.1+2"
    }
  }
}

variable "kubeconfig" {
  type = string
}

variable "namespace" {
  type        = string
  default     = "infra-secrets"
  description = "Namespace of platform/infra-secrets, created by Argo CD"
}

variable "secrets" {
  type        = map(map(string))
  default     = {}
  sensitive   = true
  description = "OpenBao path (<namespace>/<name>) to properties, from other units (infra/<env>/cloudflare's output secrets)"
}

variable "tailscale_auth_key" {
  type        = string
  default     = ""
  sensitive   = true
  description = "TF_VAR_tailscale_auth_key from ~/.config/homelab/secrets.env; empty: not written"
}

variable "protect" {
  type        = bool
  default     = false
  description = "Refuse to replace or destroy the WireGuard key (production): every peer would need the new public key"
}

# The cluster's WireGuard key (apps/wireguard.yaml); peers need its public key (output)
resource "wireguard_asymmetric_key" "wireguard" {}

# prevent_destroy cannot take a variable, so it guards the key from a resource of its own (as infra/_modules/openbao)
resource "terraform_data" "protected" {
  count            = var.protect ? 1 : 0
  triggers_replace = [wireguard_asymmetric_key.wireguard.public_key]

  lifecycle {
    prevent_destroy = true
  }
}

locals {
  secrets = merge(
    var.secrets,
    { "wireguard/private-key" = { "private-key" = wireguard_asymmetric_key.wireguard.private_key } },
    var.tailscale_auth_key == "" ? {} : { "tailscale/auth-key" = { "auth-key" = var.tailscale_auth_key } },
  )
  manifest = yamlencode({
    apiVersion = "v1"
    kind       = "List"
    items = [for path, data in local.secrets : {
      apiVersion = "v1"
      kind       = "Secret"
      metadata   = { name = replace(path, "/", "."), namespace = var.namespace }
      stringData = data
    }]
  })
}

# Separate from the Secrets below so its timeout message shows: OpenTofu hides the output of a provisioner whose
# environment holds secrets
resource "terraform_data" "namespace" {
  triggers_replace = [plantimestamp()]

  provisioner "local-exec" {
    command = "sh ${abspath("${path.module}/wait-namespace.sh")}"
    environment = {
      KUBECONFIG = var.kubeconfig
      NAMESPACE  = var.namespace
    }
  }
}

# Applied on every run (an idempotent server-side apply): a rebuilt cluster or a deleted Secret gets the same values
resource "terraform_data" "secrets" {
  triggers_replace = [plantimestamp()]
  depends_on       = [terraform_data.namespace]

  provisioner "local-exec" {
    command = "sh ${abspath("${path.module}/apply-secrets.sh")}"
    environment = {
      KUBECONFIG = var.kubeconfig
      MANIFEST   = local.manifest
    }
  }
}

output "wireguard_public_key" {
  value       = wireguard_asymmetric_key.wireguard.public_key
  description = "The cluster's WireGuard public key, for its peers"
}
```

const ntfyURL = "https://ntfy.127-0-0-1.nip.io"

// ntfyRequest sends method to path with a bearer token (none when empty) and returns the status and body
func ntfyRequest(t *testing.T, method, path, token, body string) (int, string) {
	req, err := http.NewRequest(method, ntfyURL+path, strings.NewReader(body))
	require.NoError(t, err)
	if token != "" {
		req.Header.Set("Authorization", "Bearer "+token)
	}
	resp, err := insecureClient.Do(req)
	if err != nil {
		return 0, err.Error()
	}
	defer resp.Body.Close()
	raw, _ := io.ReadAll(resp.Body)
	return resp.StatusCode, string(raw)
}

func waitForNtfy(t *testing.T) {
	require.Eventually(t, func() bool {
		status, _ := ntfyRequest(t, http.MethodGet, "/v1/health", "", "")
		return status == http.StatusOK
	}, 20*time.Minute, 15*time.Second, "ntfy does not answer through the Gateway")
}

func ntfyToken(t *testing.T, user string) string {
	return "tk_" + secretValue(t, "global-secrets", "ntfy."+user+"-token", "token")
}

// Published through the Tunnel in production: nothing without credentials
func TestNtfyDeniesAnonymous(t *testing.T) {
	secretsSandboxOnly(t)
	waitForNtfy(t)
	status, _ := ntfyRequest(t, http.MethodPost, "/alerts", "", "anonymous")
	assert.Equal(t, http.StatusForbidden, status, "anonymous publish")
	status, _ = ntfyRequest(t, http.MethodGet, "/alerts/json?poll=1", "", "")
	assert.Equal(t, http.StatusForbidden, status, "anonymous subscribe")
	status, _ = ntfyRequest(t, http.MethodPost, "/v1/account", "", `{"username":"x","password":"y"}`)
	assert.NotEqual(t, http.StatusOK, status, "signup is off")
}

// phone reads topic alerts and cannot publish; alerts publishes and cannot read
func TestNtfyUsers(t *testing.T) {
	secretsSandboxOnly(t)
	waitForNtfy(t)
	phone, alerts := ntfyToken(t, "phone"), ntfyToken(t, "alerts")
	status, _ := ntfyRequest(t, http.MethodPost, "/alerts", phone, "from phone")
	assert.Equal(t, http.StatusForbidden, status, "phone published")

# Alerts

Alertmanager posts alerts to ntfy (`apps/ntfy.yaml`), topic `alerts`, published at `https://ntfy.<domain>` through the
Cloudflare Tunnel. Nothing is readable without a user: `phone` reads, `alerts` (Alertmanager) publishes.

## Subscribe on a phone

1. Install ntfy ([Android](https://play.google.com/store/apps/details?id=io.heckel.ntfy) or

message.

The `Watchdog` alert fires all the time. Each heartbeat replaces a message scheduled 15 minutes ahead ("Monitoring
heartbeat missing"): if Prometheus or Alertmanager stop, it is delivered. If ntfy, the Tunnel or the whole cluster
