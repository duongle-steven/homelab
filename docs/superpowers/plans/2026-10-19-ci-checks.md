# Step 10a: GitHub Actions Basic Checks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pull requests into `dev` and `master` run the basic checks on GitHub Actions in the Nix dev shell and report
one status, `checks`, which a repository ruleset requires.

**Architecture:** `scripts/ci-check <check>|all` holds every basic check's command (CI and the workstation call the
same script); `lab test charts` names the charts a diff touches; `scripts/lint` gathers yamllint, shellcheck and
actionlint. `.github/workflows/checks.yaml` runs `scripts/ci-check` once per check in a matrix inside `nix develop`, and
a final job `checks` sums the matrix. `.github/rulesets/protect-dev-master.json` is applied with `gh api`.

**Tech Stack:** GitHub Actions (`actions/checkout` v7.0.1, `cachix/install-nix-action` v31.11.2,
`nix-community/cache-nix-action` v7.0.2), Nix flakes, Go 1.26 (cobra), actionlint 1.7.12, yamllint, shellcheck, `gh`.

**Spec:** `docs/superpowers/specs/2026-10-19-ci-checks-design.md`

## Global Constraints

- Branch `feat/ci-checks` from `dev` (worktree `/home/nixos/homelab-ci`); never commit to `dev` or `master`.
- Actions pinned by full commit SHA, version in a comment: `actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1`,
  `cachix/install-nix-action@448cde739abec1eaf0646249e3d25bb8d9bc7702 # v31.11.2`,
  `nix-community/cache-nix-action@7df957e333c1e5da7721f60227dbba6d06080569 # v7.0.2`.
- `permissions: contents: read`; no `${{ }}` expression inside a `run:` script (pass values through `env:`).
- One required status: the job `checks`. The ruleset is applied only after the workflow passed once, and every `gh api`
  call that changes GitHub settings waits for the user's approval.
- Tool versions come only from `flake.nix`.

## Review Focus

1. **A push that creates a branch** (`github.event.before` is forty zeros): `lab test charts` must render every chart,
   not fail on an unknown base. Pinned in Task 1 (`TestChartsZeroBaseRendersAll`).
2. **A deleted chart or app file** in the diff: it must be skipped, not rendered (render-chart would fail). Pinned in
   Task 1 (`TestChartsSkipsDeleted`).
3. **A pull request from a fork:** read-only token, no cache save; the checks still run. Pinned by the workflow's
   `permissions` and by not depending on secrets (Task 3, actionlint and review).
4. **Script injection:** a branch name or PR title must never reach a shell unquoted; values reach `run:` only through
   `env:`. Pinned in Task 3 (a grep step: no `${{` inside `run:` blocks).
5. **A cancelled matrix job** (newer push): `checks` must report failure for that run, not success. Pinned in Task 3
   (`checks` tests `needs.check.result == success`, which is `cancelled` then).

package scope

import (
	"os"
	"path"
	"path/filepath"
	"sort"
	"strings"

	"github.com/bmatcuk/doublestar/v4"
)

// chartRoots hold wrapper charts (a directory with Chart.yaml) and, under apps/, app files
var chartRoots = []string{"system", "platform", "apps"}

// Changes to these render every chart: they feed every render (scripts/render-chart, the values it passes, the apps
// ApplicationSet's app-template pin in system/argocd)
var renderAll = []string{"scripts/render-chart", "scripts/env-values", "infra/*/cluster/config.json", "system/argocd/values*.yaml"}

// Charts lists the render targets (chart directories and apps/<name>.yaml) the changed files touch, or all of them;
// targets that no longer exist are left out.
func Charts(root string, files []string, all bool) ([]string, error) {
	targets := map[string]bool{}
	for _, f := range files {
		for _, pattern := range renderAll {
			if ok, _ := doublestar.Match(pattern, f); ok {
				all = true
			}
		}
	}
	if all {
		return allCharts(root)
	}
	for _, f := range files {
		if t := target(root, f); t != "" {
			targets[t] = true
		}
	}
	return sorted(targets), nil
}

// target is the chart directory or app file a path belongs to, "" when none exists
func target(root, f string) string {
	if path.Dir(f) == "apps" && strings.HasSuffix(f, ".yaml") {
		if exists(filepath.Join(root, f)) {
			return f
		}
		return ""
	}
	for dir := path.Dir(f); strings.Contains(dir, "/"); dir = path.Dir(dir) {
		if exists(filepath.Join(root, dir, "Chart.yaml")) {
			if top := strings.SplitN(dir, "/", 2)[0]; contains(chartRoots, top) {
				return dir
			}
			return ""
		}
	}
	return ""
}

func allCharts(root string) ([]string, error) {
	targets := map[string]bool{}
	for _, top := range chartRoots {
		charts, err := filepath.Glob(filepath.Join(root, top, "*", "Chart.yaml"))
		if err != nil {
			return nil, err
		}
		for _, c := range charts {
			rel, err := filepath.Rel(root, filepath.Dir(c))
			if err != nil {
				return nil, err
			}
			targets[filepath.ToSlash(rel)] = true
		}
	}
	apps, err := filepath.Glob(filepath.Join(root, "apps", "*.yaml"))
	if err != nil {
		return nil, err
	}
	for _, a := range apps {
		targets["apps/"+filepath.Base(a)] = true
	}
	return sorted(targets), nil
}

func exists(p string) bool {
	_, err := os.Stat(p)
	return err == nil
}

func contains(list []string, s string) bool {
	for _, l := range list {
		if l == s {
			return true
		}
	}
	return false
}

func sorted(set map[string]bool) []string {
	out := []string{}
	for k := range set {
		out = append(out, k)
	}
	sort.Strings(out)
	return out
}

```sh
#!/bin/sh
# The basic checks, one per name, as GitHub Actions runs them (.github/workflows/checks.yaml) and as the workstation
# runs them before a commit (scripts/ci-check all). Run in the dev shell (nix develop). render renders the charts
# changed since $BASE (default origin/dev; lab test charts).
set -eu
cd "$(git rev-parse --show-toplevel)"
offline_tests='TestSmokeAppsForEnv|TestIdentity(TOTPWaitsForNextStep|PKCE)|TestGatewayRouteReady|TestGatewayNodeAddressFromInspect|TestNodeRestart(Blockers|WatchdogJobs)|TestIstioCNIWatchdog|TestState'
checks='render go cli infra docs mesh env-config secret-stores lint'

check() {
	case "$1" in
		render)
			targets=$(go -C cli run ./cmd/lab test charts --base "${BASE:-origin/dev}")
			for t in $targets; do
				echo "render $t"
				scripts/render-chart "$t" >/dev/null
				scripts/render-chart "$t" dev >/dev/null
			done ;;
		go) (cd test && go vet ./... && go test -run "$offline_tests" ./...) ;;
		cli) make -C cli test check ;;
		infra) env -u HOMELAB_STATE_PASSPHRASE make -C infra check ;;
		docs) mkdocs build --strict ;;
		mesh) scripts/check-mesh-policies ;;
		env-config) scripts/check-env-config ;;
		secret-stores) scripts/check-secret-stores ;;
		lint) scripts/lint ;;
		*) echo "ci-check: unknown check $1 (one of: $checks, all)" >&2; exit 2 ;;
	esac
}

if [ "${1:?usage: ci-check <check>|all}" = all ]; then
	for c in $checks; do echo "== $c"; check "$c"; done
else
	check "$1"
fi
```

```yaml
# The basic checks (scripts/ci-check) on every pull request into dev or master and every push to them, in the Nix dev
# shell. The ruleset (.github/rulesets/protect-dev-master.json) requires the job "checks".
name: checks

on:
  pull_request:
    branches: [dev, master]
  push:
    branches: [dev, master]

permissions:
  contents: read

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  # A newer push to a pull request replaces its run; runs on dev and master always finish
  cancel-in-progress: ${{ github.event_name == 'pull_request' }}

jobs:
  check:
    name: ${{ matrix.check }}
    runs-on: ubuntu-24.04
    timeout-minutes: 30
    strategy:
      fail-fast: false
      matrix:
        check: [render, go, cli, infra, docs, mesh, env-config, secret-stores, lint]
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          fetch-depth: 0 # lab test charts diffs against the base
          persist-credentials: false
      - uses: cachix/install-nix-action@448cde739abec1eaf0646249e3d25bb8d9bc7702 # v31.11.2
      - uses: nix-community/cache-nix-action@7df957e333c1e5da7721f60227dbba6d06080569 # v7.0.2
        with:
          primary-key: nix-${{ runner.os }}-${{ hashFiles('flake.nix', 'flake.lock') }}
          restore-prefixes-first-match: nix-${{ runner.os }}-
          gc-max-store-size-linux: 8G
      - name: scripts/ci-check ${{ matrix.check }}
        env:
          CHECK: ${{ matrix.check }}
          # The pull request's base, or the previous commit of a push (forty zeros for a new branch: lab renders all)
          BASE: ${{ github.event.pull_request.base.sha || github.event.before }}
        run: nix develop --command scripts/ci-check "$CHECK"

  # The one required status: fails unless every check succeeded (a cancelled or skipped check fails it too)
  checks:
    if: always()
    needs: check
    runs-on: ubuntu-24.04
    steps:
      - name: every check succeeded
        env:
          RESULT: ${{ needs.check.result }}
        run: test "$RESULT" = success
```

## A failed run

## Protected branches

The ruleset `protect-dev-master` (`.github/rulesets/protect-dev-master.json`): changes reach `dev` and `master` only
through pull requests whose `checks` passed (no approval needed), never by a direct push, a force-push or a deletion.
Repository admins may merge a pull request whose checks failed (`gh pr merge --admin`), for a GitHub Actions outage
only: run `scripts/ci-check all` first. Branch `sandbox` is not protected (`make dev` force-pushes it).

```sh
# Create it (once)
gh api --method POST 'repos/{owner}/{repo}/rulesets' --input .github/rulesets/protect-dev-master.json
# Its ID
id=$(gh api 'repos/{owner}/{repo}/rulesets' --jq '.[] | select(.name == "protect-dev-master") | .id')
# Update it after editing the file
gh api --method PUT "repos/{owner}/{repo}/rulesets/$id" --input .github/rulesets/protect-dev-master.json
# Show it, and the rules a branch gets
gh api "repos/{owner}/{repo}/rulesets/$id"
gh api 'repos/{owner}/{repo}/rules/branches/dev'
# Remove it
gh api --method DELETE "repos/{owner}/{repo}/rulesets/$id"
```

`gh` fills `{owner}/{repo}` from the repository you are in.
