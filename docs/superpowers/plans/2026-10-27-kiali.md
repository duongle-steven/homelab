# Kiali (Step 14d) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only Kiali for admins on the LAN Gateway, with Istio's metrics scraped so its graph has data.

**Architecture:**
- **Metrics:** `system/istio-system` gains PodMonitors for ztunnel, istiod and the Gateways' Envoy, and whatever lets
  Prometheus reach them.
- **Kiali:** a new component `system/kiali` wraps `kiali-server` 2.33.0. It signs in with Kanidm's `openid` and holds
  its own HTTPRoute, AuthorizationPolicy and Kanidm client.

**Tech Stack:** Helm, kube-prometheus-stack's PodMonitor, Istio ambient, kaniop, Go sandbox tests.

**Spec:** `docs/superpowers/specs/2026-10-27-kiali-design.md`

## Global Constraints

- `kiali-server` chart 2.33.0 from `https://kiali.org/helm-charts`, pinned.
- Kiali has `view_only_mode: true` and `disable_rbac: true`. Only `homelab-admins` gets a scope on Kanidm client
  `kiali`.
- The route `kiali.{{ .Values.global.baseDomain }}` is on `istio-system/gateway` only, never `public`.
- No IP address or domain in the chart (`scripts/check-env-config`).
- No PVC.
- The new secret has an entry in `cli/internal/rotate/catalog.yaml`.
- `scripts/check-mesh-policies` passes.
- `scripts/ci-check all` runs before each commit. `make dev` runs only from `/home/nixos/homelab`.

## Review Focus

1. **A signed-in non-admin** (homelab-editors, homelab-users, no group) must not reach Kiali. Test: `TestSSOKiali`
   refuses `dev-editor`, `dev-viewer` and `dev-outsider`.
2. **A write through Kiali's API** (as an admin) must be refused, since the instance is read-only. Test: `TestSSOKiali`
   PATCHes an Istio object through Kiali and expects a refusal.
3. **Kiali on the public Gateway** must never render. Test: `TestKialiRender` (offline) finds exactly one HTTPRoute,
   with parent `gateway`.
4. **An empty graph** (metrics missing, or Prometheus blocked by the mesh): the graph API must return edges. Test:
   `TestMeshMetrics` checks the series, and `TestSSOKiali` checks the graph has at least one edge.
