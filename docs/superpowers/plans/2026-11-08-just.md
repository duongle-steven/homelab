# 14b-1: `just` replaces make — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** four justfiles replace the four Makefiles with the same behaviour and `just`-style options.

**Architecture:** a root `justfile` (`mod infra`, `mod cli`, `mod test`) holds the sandbox and testbed recipes; each
module holds its directory's commands and runs there. Parameters are exported (`$name`) so regexes and reasons reach
the shell unparsed; long bodies are bash shebang recipes.

**Tech Stack:** just 1.59.0 (`nix/just.nix`), bash, Go tests (`test/ci_scripts_test.go`).

**Spec:** `docs/superpowers/specs/2026-11-08-just-design.md`

## Global Constraints

- just 1.59.0 from its release (`nix/just.nix`, in the dev shell).
- Interface exactly as the spec's table; `just test run [--env] [--filter] [--format]` (verified: `just test --filter`
  is refused, a module's default recipe takes no options).
- `set shell := ["bash", "-euo", "pipefail", "-c"]` in every justfile; recursive calls use `{{ just_executable() }}`.
- `lab` runs as `go -C cli run ./cmd/lab` (overridable by `HOMELAB_LAB`), `terragrunt` overridable by
  `HOMELAB_TERRAGRUNT`, for the offline tests' fakes.
- Old specs and plans in `docs/superpowers/` stay as they are.

## Review Focus

- A `--tests` regex holding `$`, `|`, `(` or quotes reaches `lab` and `go test` byte for byte (offline test).
- A `--break-glass` reason with quotes and `$` reaches `lab` unchanged (offline test, as the make test had).
- `just dev` from a worktree, a dirty tree or a `--revision` that is not HEAD is refused before any push (offline test
  for the last two, as `TestSandboxClean`).
- A failing main run skips the alone tests and `warm-image-cache --node` still runs; the exit status is the failure's.
- `just` run from a subdirectory (`cli/`) still resolves paths from the root.
