# Step 10d: Renovate through our own GitHub App — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Renovate in the production cluster opens pull requests into `dev` on GitHub as our own GitHub App, with a one-hour installation token from ESO and the App's key kept by OpenTofu.

**Architecture:** `infra/_modules/kept-value` keeps a value given once (the App's private key) in OpenTofu's state; `infra/_modules/secrets` publishes it as `renovate/github-app` through `platform/infra-secrets` into OpenBao. `platform/renovate` copies it into namespace `renovate`, an ESO `GithubAccessToken` generator mints the token every 30 minutes into `renovate-secret`, and the Renovate chart's CronJob runs at 05:00. `renovate.json5` targets `dev` and labels its pull requests `sandbox`; `sandbox.yaml` cancels older `dev` runs.

**Tech Stack:** OpenTofu (builtin `terraform_data`), Terragrunt, Helm (Renovate chart 46.372.0, image 44.172.0), External Secrets 2.12 (`generators.external-secrets.io/v1alpha1` `GithubAccessToken`), Go tests (testify), nixpkgs `renovate` (config validator), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-20-renovate-design.md`

## Global Constraints

- Chart `renovate` 46.372.0 from `https://docs.renovatebot.com/helm-charts` (its image 44.172.0, the chart's default, pinned in values).
- The token ExternalSecret: `refreshPolicy: Periodic`, `refreshInterval: 30m`; never `CreatedOnce`.
- Generator permissions exactly: `contents: write`, `pull_requests: write`, `workflows: write`, `issues: write`, `checks: read`, `statuses: read`; `repositories: [homelab]`.
- OpenBao path `renovate/github-app`, property `private-key`; the key file comes from `HOMELAB_GITHUB_APP_KEY` (a path) only; never printed, never committed.
- Renovate config: `platform: github`, `autodiscover: true`, `autodiscoverFilter: ["duongle-steven/*"]`, `onboarding: false`, `requireConfig: "required"`; repository config `baseBranches: ["dev"]`, `labels: ["sandbox"]`, no automerge.
- CronJob `0 5 * * *`, time zone `Asia/Ho_Chi_Minh` (written in `platform/renovate/values.yaml`: the chart cannot read `global.timezone`; listed with kured in CLAUDE.md).
- Renovate stays out of the sandbox's component list (`system/argocd/values-dev.yaml`).
- Every task ends with `direnv exec . scripts/ci-check all` passing before its commit; commits end with the session's attribution lines.

## Rulings (where this plan refines the spec)

- The time zone is written in `platform/renovate/values.yaml` (spec: "in `global.timezone`"): the subchart's `cronjob.timeZone` cannot be templated from a global, like kured's; CLAUDE.md's list of settings outside `config.json` gains it.
- The kept key is its own module, `infra/_modules/kept-value` (spec: "a `terraform_data` in `infra/_modules/secrets`"), so its behaviour is tested with `tofu` alone, offline. A value given while an empty one is stored (the unit applied before the App existed) fails with a message to apply with `-replace`, instead of being ignored silently.
- The App's IDs and bot id exist only once the App does: Task 1 writes the how-to, then execution stops for the user to create and install the App and send the App ID, installation ID, slug and bot id (none is secret).

## Review Focus

1. A `make infra env=production` run before the App exists (no `HOMELAB_GITHUB_APP_KEY`): nothing about Renovate may fail the infrastructure apply — Task 2 tests an empty value.
2. The key given after an empty value was stored: must fail loudly, never be dropped — Task 2 tests it.
3. A rotated key given without `-replace`: must fail, not keep the old key silently — Task 2 tests it.
4. The token ExternalSecret copied from `global-secrets`' style with `CreatedOnce`: Renovate would stop after an hour — Task 3's offline test pins `Periodic`.
5. A manual `workflow_dispatch` of `sandbox.yaml` cancelling a `dev` run, or the reverse — Task 5 sets separate groups and checks them with `yq`.

```markdown
# Renovate

Renovate runs in the production cluster (`platform/renovate`, daily at 05:00) and opens pull requests into `dev` on
GitHub as the GitHub App `homelab-renovate`. Its pull requests run `checks` and, labelled `sandbox`, the sandbox.
The App's private key goes through OpenTofu into OpenBao; External Secrets mints a one-hour installation token from it
every 30 minutes (`renovate-secret`).

## Create the App (once)

1. GitHub → Settings → Developer settings → GitHub Apps → New GitHub App: name `homelab-renovate`, homepage the
   repository's URL, **Webhook: off**.
2. Repository permissions: Contents, Pull requests, Workflows, Issues (Renovate's Dependency Dashboard): **Read and
   write**; Commit statuses, Checks: **Read-only**; Metadata: Read-only (always). No organization or account
   permissions. "Only on this account".
3. Create it, note the **App ID**, then **Generate a private key** (a `.pem` downloads once).
4. Install App → your account → **Only select repositories** → `homelab`. The installation's URL ends with its
   **installation ID** (`.../settings/installations/<id>`).
5. The bot's user id, for Renovate's commit author: `gh api '/users/homelab-renovate[bot]' --jq .id`.

App ID, installation ID and bot id are not secrets: they live in `platform/renovate/values.yaml`.

## Give the key to production (once, and after a rotation)

```sh
HOMELAB_GITHUB_APP_KEY=~/Downloads/homelab-renovate.<date>.private-key.pem make infra env=production
```

OpenTofu keeps the key in its encrypted state (`infra/production/secrets`); later runs need no file, so delete it.
If the unit was applied before the key existed, apply once with the key and
`-replace=module.github_app_key.terraform_data.kept` in `infra/production/secrets`
(`terragrunt apply -replace=...`); the plain run refuses rather than ignoring the key.

## Rotate the key

Generate a new key on the App's page, then in `infra/production/secrets`:

```sh
HOMELAB_GITHUB_APP_KEY=<new.pem> terragrunt apply -replace=module.github_app_key.terraform_data.kept
```

Delete the old key on GitHub once Renovate ran with the new one.

## Add a repository

Install the App on it (App → Configure → Repository access) and add a `renovate.json5`; the next run finds it
(`autodiscover`, limited to `duongle-steven/*`). Renovate skips repositories without a config.
```

func TestKeptValue(t *testing.T) {

	require.NoError(t, err)
	dir := t.TempDir()
	require.NoError(t, os.WriteFile(filepath.Join(dir, "main.tf"), []byte(`
variable "value" {
  type      = string
  default   = ""
  sensitive = true
}
module "kept" {
  source = "`+module+`"
  value  = var.value
}
output "value" {
  value     = nonsensitive(module.kept.value)
}
`), 0o644))
	tofu := func(args ...string) (string, error) {
		cmd := exec.Command("tofu", append([]string{"-chdir=" + dir}, args...)...)
		cmd.Env = append(os.Environ(), "TF_IN_AUTOMATION=1")
		out, err := cmd.CombinedOutput()
		return string(out), err
	}
	apply := func(value string, extra ...string) (string, error) {
		return tofu(append([]string{"apply", "-auto-approve", "-input=false", "-no-color", "-var", "value=" + value}, extra...)...)
	}
	output := func() string {
		out, err := tofu("output", "-raw", "value")
		require.NoError(t, err, out)
		return strings.TrimSpace(out)
	}
	out, err := tofu("init", "-input=false", "-no-color")
	require.NoError(t, err, out)

	out, err = apply("key-a")
	require.NoError(t, err, out)
	assert.Equal(t, "key-a", output())

	out, err = apply("")
	require.NoError(t, err, out)
	assert.Equal(t, "key-a", output(), "an empty value replaced the kept one")

	out, err = apply("key-b")
	assert.Error(t, err, "a different value was taken without -replace:\n%s", out)
	assert.Contains(t, out, "-replace")
	assert.Equal(t, "key-a", output())

	out, err = apply("key-b", "-replace=module.kept.terraform_data.kept")
	require.NoError(t, err, out)
	assert.Equal(t, "key-b", output())
}

# infra/_modules/kept-value/main.tf
# A value given once (the GitHub App's private key) and kept in this unit's encrypted state: later applies may give
# none. A different value is refused until applied with -replace=<module>.terraform_data.kept, so a key is never
# dropped or swapped silently.
variable "value" {
  type      = string
  default   = ""
  sensitive = true
}

resource "terraform_data" "kept" {
  input = var.value

  lifecycle {
    ignore_changes = [input]
    postcondition {
      condition     = var.value == "" || var.value == self.output
      error_message = "A different value is kept: apply with -replace=<this module>.terraform_data.kept to take the new one."
    }
  }
}

output "value" {
  value     = terraform_data.kept.output
  sensitive = true
}
```

package test

import (
	"os/exec"
	"strings"

	"github.com/stretchr/testify/assert"

func renderRenovate(t *testing.T, expr string) string {
	t.Helper()
	cmd := exec.Command("sh", "-c", `scripts/render-chart platform/renovate | yq -N "$0"`, expr)
	cmd.Dir = ".."
	out, err := cmd.CombinedOutput()
	require.NoError(t, err, string(out))
	return strings.TrimSpace(string(out))
}

// Renovate's token comes from our GitHub App, scoped to homelab and minted again every 30 minutes (never created
// once: it expires after an hour); its CronJob runs at 05:00 local time
func TestRenovateGitHubApp(t *testing.T) {
	assert.Equal(t, `{"checks":"read","contents":"write","issues":"write","pull_requests":"write","statuses":"read","workflows":"write"}`,
		renderRenovate(t, `select(.kind == "GithubAccessToken") | .spec.permissions | to_entries | sort_by(.key) | from_entries | to_json(0)`))
	assert.Equal(t, `["homelab"]`, renderRenovate(t, `select(.kind == "GithubAccessToken") | .spec.repositories | to_json(0)`))
	token := `select(.kind == "ExternalSecret" and .spec.target.name == "renovate-secret")`
	assert.Equal(t, "30m", renderRenovate(t, token+` | .spec.refreshInterval`))
	assert.Contains(t, []string{"Periodic", "null"}, renderRenovate(t, token+` | .spec.refreshPolicy`))
	assert.Equal(t, "GithubAccessToken", renderRenovate(t, token+` | .spec.dataFrom[0].sourceRef.generatorRef.kind`))
	assert.Equal(t, "0 5 * * *", renderRenovate(t, `select(.kind == "CronJob") | .spec.schedule`))
	assert.Equal(t, "Asia/Ho_Chi_Minh", renderRenovate(t, `select(.kind == "CronJob") | .spec.timeZone`))
	all := renderRenovate(t, `.`)
	assert.NotContains(t, all, "forgejo")
	assert.NotContains(t, all, "renovate/forgejo")
}

kind: ExternalSecret
metadata:
  name: renovate-github-app
  namespace: {{ .Release.Namespace }}
spec:
  secretStoreRef:
    kind: SecretStore
    name: openbao
  target:
    name: renovate-github-app
  data:

      remoteRef:
        key: renovate/github-app
        property: private-key
---
apiVersion: generators.external-secrets.io/v1alpha1
kind: GithubAccessToken
metadata:
  name: renovate
  namespace: {{ .Release.Namespace }}
spec:
  appID: {{ .Values.githubApp.appID | quote }}
  installID: {{ .Values.githubApp.installationID | quote }}
  # Narrower than the App: only what Renovate needs, only homelab

    issues: write

    statuses: read

        name: renovate-github-app
        key: private-key
---

apiVersion: external-secrets.io/v1

  refreshInterval: 30m
