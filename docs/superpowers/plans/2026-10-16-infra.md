# Infra (Step 7a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Terragrunt units under `infra/` create, bootstrap and remove the sandbox, and bootstrap production's Argo CD, replacing `metal/Makefile`'s k3d targets and `system/bootstrap.yml`.

**Architecture:** `infra/root.hcl` (local state, kubeconfig path) includes per-environment units; module `k3d` wraps `k3d` and the socat proxy in `terraform_data` resources; module `argocd` renders `system/argocd` and applies it server-side once, re-applied only when its files change. The root `Makefile` drives Terragrunt.

**Tech Stack:** OpenTofu 1.13, Terragrunt 1.1, hashicorp/external 2.4.2, k3d 5.9, Helm, kubectl, GNU make.

**Spec:** `docs/superpowers/specs/2026-10-16-infra-design.md`

## Global Constraints

- Layout: `infra/root.hcl`, `infra/Makefile`, `infra/_modules/k3d`, `infra/_modules/argocd`, `infra/sandbox/cluster`, `infra/sandbox/argocd`, `infra/production/argocd`.
- State: local, `<repo>/.state/<env>/<unit>/terraform.tfstate`, git-ignored.
- Kubeconfig: `infra/<env>/kubeconfig.yaml` (`*kubeconfig.yaml` is already git-ignored).
- Bootstrap: `kubectl apply --server-side --field-manager argocd-controller --force-conflicts` of `helm template --include-crds system/argocd`; production picks `values-seed.yaml` when no pod `app.kubernetes.io/instance=forgejo` is Running, else `values.yaml`; the sandbox uses `values-dev.yaml`.
- Production's bootstrap resource has `prevent_destroy`.
- Unchanged: production nodes via `make -C metal` (Ansible), `external/`.

## Review Focus

1. A second apply on an unchanged sandbox must change nothing (proxy keyed on the node address, bootstrap keyed on file hashes). Pinned in Task 2 and Task 3 (`plan` shows no changes) and Task 5.
2. Destroy must not leave a running proxy, cluster, Docker network or kubeconfig, and must work when the cluster is already gone. Pinned in Task 2 (destroy, then destroy again).
3. `prevent_destroy` cannot take a variable: production's protected resource must still be the only one created there. Pinned in Task 3 (`plan` lists exactly one resource per environment).
4. The bootstrap hash must ignore files Helm writes (`charts/`, `Chart.lock`), or every run re-applies. Pinned in Task 3.
5. Terragrunt runs `cluster` before `argocd` in the sandbox, and `run --all destroy` removes `argocd`'s state before deleting the cluster. Pinned in Task 4/5 (`make dev`, `make dev-clean`).

`infra/_modules/k3d/main.tf`:

```hcl
# The k3d sandbox: one k3s server (k3d.yaml), the latest Gateway API CRDs in k3s's auto-deploy manifests (k3s's
# packaged ones are disabled), and a localhost proxy: under WSL mirrored networking Windows cannot reach ports
# Docker publishes, so a host-network socat forwards 127.0.0.1:80/443/22 to the node (ServiceLB serves the Gateway)
terraform {
  required_version = ">= 1.13"
  required_providers {
    external = {
      source  = "hashicorp/external"
      version = "2.4.2"
    }
  }
}

variable "kubeconfig" {
  type = string
}

variable "name" {
  type    = string
  default = "homelab-dev"
}

variable "gateway_api_version" {
  type    = string
  default = "v1.6.3"
}

variable "proxy_bind" {
  type    = string
  default = "127.0.0.1"
}

locals {
  config   = abspath("${path.module}/k3d.yaml")
  manifest = abspath("${path.module}/gateway-api-${var.gateway_api_version}.yaml")
  node     = "k3d-${var.name}-server-0"
  proxy    = "${var.name}-proxy"
}

resource "terraform_data" "cluster" {
  triggers_replace = [filesha1(local.config), var.gateway_api_version, var.name]
  input            = { name = var.name, kubeconfig = var.kubeconfig }

  provisioner "local-exec" {
    command = <<-EOT
      set -eu
      [ -s "${local.manifest}" ] || curl -fsSL -o "${local.manifest}" \
        https://github.com/kubernetes-sigs/gateway-api/releases/download/${var.gateway_api_version}/standard-install.yaml
      k3d cluster list ${var.name} >/dev/null 2>&1 || k3d cluster create --config "${local.config}" \
        --volume "${local.manifest}:/var/lib/rancher/k3s/server/manifests/gateway-api.yaml@server:*"
      k3d kubeconfig get ${var.name} > "${var.kubeconfig}"
    EOT
  }

  provisioner "local-exec" {
    when    = destroy
    command = "k3d cluster delete ${self.input.name}; rm -f '${self.input.kubeconfig}'"
  }
}

# The node's address (it can change when the cluster is recreated)
data "external" "node" {
  depends_on = [terraform_data.cluster]
  program    = ["sh", "-c", "printf '{\"ip\":\"%s\"}' \"$(docker inspect -f '{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' ${local.node})\""]
}

resource "terraform_data" "proxy" {
  triggers_replace = [data.external.node.result.ip, var.proxy_bind]
  input            = { name = local.proxy }

  provisioner "local-exec" {
    command = <<-EOT
      set -eu
      node="${data.external.node.result.ip}"
      [ -n "$node" ] || { echo "the k3d node ${local.node} is not running"; exit 1; }
      docker rm -f ${local.proxy} >/dev/null 2>&1 || true
      if ss -ltnH '( sport = :80 or sport = :443 or sport = :22 )' | grep -q .; then
        echo "ports 80/443/22 are already in use on this host:"; ss -ltnp '( sport = :80 or sport = :443 or sport = :22 )'; exit 1
      fi
      docker run -d --name ${local.proxy} --network host --restart unless-stopped \
        --entrypoint sh alpine/socat:1.8.1.3 -c "\
          socat TCP-LISTEN:80,bind=${var.proxy_bind},fork,reuseaddr TCP:$node:80 & \
          socat TCP-LISTEN:22,bind=${var.proxy_bind},fork,reuseaddr TCP:$node:22 & \
          exec socat TCP-LISTEN:443,bind=${var.proxy_bind},fork,reuseaddr TCP:$node:443" >/dev/null
    EOT
  }

  provisioner "local-exec" {
    when    = destroy
    command = "docker rm -f ${self.input.name} >/dev/null 2>&1 || true"
  }
}

output "kubeconfig" {
  value      = var.kubeconfig
  depends_on = [terraform_data.cluster]
}
```

`infra/_modules/argocd/bootstrap.sh`:

```sh
#!/bin/sh
# Render system/argocd and apply it once; Argo CD manages itself from then on (system/argocd is in the root
# ApplicationSet), so the field manager is Argo CD's.
# Env: KUBECONFIG, CHART (system/argocd), VALUES (file name in CHART), SEED (file used while Forgejo is not running;
# production's first install syncs from GitHub until Forgejo holds the repository)
set -eu
kubectl create namespace argocd --dry-run=client -o yaml | kubectl apply -f - >/dev/null
values="$VALUES"
if [ -n "${SEED:-}" ] && [ -z "$(kubectl get pods --all-namespaces -l app.kubernetes.io/instance=forgejo \
  --field-selector status.phase=Running -o name)" ]; then
  values="$SEED"
fi
helm dependency build "$CHART" >/dev/null
helm template argocd "$CHART" --namespace argocd --include-crds -f "$CHART/$values" \
  | kubectl apply --server-side --field-manager argocd-controller --force-conflicts -f -
```

`infra/_modules/argocd/main.tf`:

```hcl
# Bootstrap Argo CD from the repository's system/argocd chart. Applied once and again only when the chart's files
# or the chosen values change; every later change reaches the cluster through Argo CD's own sync from git.
terraform {
  required_version = ">= 1.13"
}

variable "kubeconfig" {
  type = string
}

variable "chart" {
  type        = string
  description = "Absolute path of system/argocd"
}

variable "values" {
  type        = string
  description = "Values file in the chart directory"
}

variable "seed" {
  type        = string
  default     = ""
  description = "Values file used while Forgejo is not running (production's first install)"
}

variable "protect" {
  type        = bool
  default     = false
  description = "Refuse to destroy (production)"
}

locals {
  # Helm writes charts/ and Chart.lock: hash only what the repository holds
  files = sort(setunion(fileset(var.chart, "*.yaml"), fileset(var.chart, "templates/**")))
  hash  = sha1(join("", [for f in local.files : filesha1("${var.chart}/${f}")]))
  environment = {
    KUBECONFIG = var.kubeconfig
    CHART      = var.chart
    VALUES     = var.values
    SEED       = var.seed
  }
  command = "sh ${abspath("${path.module}/bootstrap.sh")}"
}

# prevent_destroy cannot take a variable: one resource per setting, only one of them exists
resource "terraform_data" "bootstrap" {
  count            = var.protect ? 0 : 1
  triggers_replace = [local.hash, var.values, var.seed]

  provisioner "local-exec" {
    command     = local.command
    environment = local.environment
  }
}

resource "terraform_data" "protected" {
  count            = var.protect ? 1 : 0
  triggers_replace = [local.hash, var.values, var.seed]

  provisioner "local-exec" {
    command     = local.command
    environment = local.environment
  }

  lifecycle {
    prevent_destroy = true
  }
}
```
