# Step 5b: Forgejo replaces Gitea — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Gitea with Forgejo (Kanidm SSO, SSH, seeded GitOps repo that production Argo CD syncs from), production on CloudNativePG, sandbox on SQLite.

**Architecture:** A wrapper chart `platform/forgejo` around the official Forgejo chart, with our own templates for the Kanidm client, SSH `TCPRoute`, admin secret, CloudNativePG `Cluster` and a seed Job. A wrapper chart `platform/cloudnative-pg` for the operator (production only). Argo CD switches to `ops/homelab` on Forgejo with a repository credential from `global-secrets`.

**Tech Stack:** Helm wrapper charts, Argo CD ApplicationSets, kaniop `KanidmOAuth2Client`, external-secrets, Gateway API, Go tests (terratest, chromedp).

**Spec:** `docs/superpowers/specs/2026-10-14-forgejo-design.md`

## Global Constraints

- Forgejo chart `forgejo` 17.3.0 from `oci://code.forgejo.org/forgejo-helm`; image tag `16.0.6` (rootless, the chart appends `-rootless`).
- CloudNativePG chart `cloudnative-pg` 0.29.1 from `https://cloudnative-pg.github.io/charts`; PostgreSQL image `ghcr.io/cloudnative-pg/postgresql:18.6-standard-trixie`.
- Every name this repo controls is `forgejo`; `gitea` remains only where the chart or image imposes it (values key `gitea:`, init container `configure-gitea`, `GITEA_*`/`GITEA__*` env, `/data/gitea`, `/var/lib/gitea`, `/etc/gitea`) and in history (past specs and plans, `docs/reference/changelog.md`, `docs/reference/architecture/decision-records.md`, `docs/reference/roadmap.md`, the external tutorial title in `README.md`).
- Feature branch `feat/forgejo` (already created from `dev`), PR into `dev`; never commit to `dev` or `master`.
- Basic checks on the branch: `scripts/render-chart <dir>` and `scripts/render-chart <dir> dev` for every changed chart or app file; `cd test && go vet ./... && go test -run 'TestSmokeAppsForEnv|TestIdentity(HasGroup|TOTPWaitsForNextStep|PKCE)|TestGatewayRouteReady' ./...`; `mkdocs build --strict` (then `rm -r site`).
- `make dev` runs only after the PR is merged into `dev`; ask the user before merging.
- Helm replaces lists: a list overridden in `values-dev.yaml` is restated in full.
- No personal data in the repo; production `KanidmGroup`s never set `members`.

## Review Focus

1. **Kaniop secret not ready when Forgejo starts** — the pod must wait (CreateContainerConfigError) and then start normally, never run with an empty client secret: the `CLIENT_SECRET` env uses `secretKeyRef` without `optional`. Covered by `TestSSOForgejo` on a fresh sandbox.
2. **A second login of the same person** must reuse the account (no duplicate, no link-account page) and keep the admin flag in sync: `TestSSOForgejo` logs every account in twice (Task 2).
3. **Seed Job re-run** (Argo CD re-sync, script change) must not touch an existing repository: the script only creates on 404; `TestForgejoSeed` runs the script a second time against the live repository (Task 3).
4. **An account in no role group** must not get a Forgejo account: `TestSSOForgejo` checks `dev-outsider` gets "Access Denied".
5. **Sandbox-only overrides leaking into production** (SQLite, CA mounts, seed source): the production render must show `DB_TYPE=postgres`, no `homelab-dev-ca`, and the upstream seed repository (render checks in Tasks 2 and 3).

	base := "https://" + forgejoHost

	start := base + "/user/oauth2/Kanidm"

	for _, c := range []struct {

		admin   bool

// TestForgejoSeed checks the seed Job copied the GitOps repository and that Argo CD's repository
// credential reads it, as production Argo CD will.
func TestForgejoSeed(t *testing.T) {
	if os.Getenv("ENV") != "dev" {
		t.Skip("Forgejo tests run against the sandbox only")
	}
	base := "https://" + forgejoHost
	waitForApp(t, base+"/api/healthz")
	admin := secretValue(t, "forgejo", "forgejo-admin", "username")
	password := secretValue(t, "forgejo", "forgejo-admin", "password")

	var repo struct {
		Private bool `json:"private"`
		Empty   bool `json:"empty"`
	}
	require.Eventually(t, func() bool {
		return getJSON(t, "GET", base+"/api/v1/repos/ops/homelab", nil, admin, password, nil, &repo) == http.StatusOK
	}, 20*time.Minute, 15*time.Second, "ops/homelab was not seeded")
	assert.True(t, repo.Private)
	assert.False(t, repo.Empty)

	user := secretValue(t, "argocd", "argocd-repo-forgejo", "username")
	pass := secretValue(t, "argocd", "argocd-repo-forgejo", "password")
	assert.Equal(t, "http://forgejo-http.forgejo:3000/ops/homelab", secretValue(t, "argocd", "argocd-repo-forgejo", "url"))
	assert.Equal(t, http.StatusOK, getJSON(t, "GET", base+"/api/v1/repos/ops/homelab/branches/master", nil, user, pass, nil, nil))
}

// TestForgejoSeedIsIdempotent runs the seed script again against the seeded repository: it must succeed
// without touching it.
func TestForgejoSeedIsIdempotent(t *testing.T) {
	if os.Getenv("ENV") != "dev" {
		t.Skip("Forgejo tests run against the sandbox only")
	}
	options := k8s.NewKubectlOptions("", "", "forgejo")
	job, err := k8s.RunKubectlAndGetOutputE(t, options, "get", "jobs", "-o", "jsonpath={.items[0].metadata.name}")
	require.NoError(t, err)
	require.NotEmpty(t, job)
	rerun := job + "-rerun"
	_, err = k8s.RunKubectlAndGetOutputE(t, options, "create", "job", "--from=job/"+job, rerun)
	require.NoError(t, err)
	defer k8s.RunKubectlE(t, options, "delete", "job", rerun)
	_, err = k8s.RunKubectlAndGetOutputE(t, options, "wait", "--for=condition=complete", "--timeout=5m", "job/"+rerun)
	require.NoError(t, err)

`platform/forgejo/files/seed.sh`:

```sh
#!/bin/sh
# Seeds the GitOps repository once: creates the org ops and copies SEED_REPOSITORY into ops/homelab.
# Never changes an existing org or repository: after the seed, Forgejo is the source of truth.
set -eu

base=http://forgejo-http:3000
api="${base}/api/v1"

# status <curl args...>: prints the HTTP status, authenticated as the local admin
status() {
    curl --silent --output /dev/null --write-out '%{http_code}' --max-time 600 \
        --user "${FORGEJO_ADMIN_USERNAME}:${FORGEJO_ADMIN_PASSWORD}" "$@"
}

until curl --silent --fail --output /dev/null "${base}/api/healthz"; do
    echo "waiting for Forgejo"
    sleep 5
done

case "$(status "${api}/orgs/ops")" in
    200) echo "org ops exists" ;;
    404)
        code="$(status --request POST --header 'Content-Type: application/json' \
            --data '{"username": "ops", "visibility": "private"}' "${api}/orgs")"
        [ "${code}" = 201 ] || { echo "creating org ops: HTTP ${code}" >&2; exit 1; }
        echo "created org ops"
        ;;
    *) echo "checking org ops: unexpected status" >&2; exit 1 ;;
esac

case "$(status "${api}/repos/ops/homelab")" in
    200) echo "ops/homelab exists" ;;
    404)
        code="$(status --request POST --header 'Content-Type: application/json' \
            --data "{\"clone_addr\": \"${SEED_REPOSITORY}\", \"repo_owner\": \"ops\", \"repo_name\": \"homelab\", \"service\": \"git\", \"mirror\": false, \"private\": true}" \
            "${api}/repos/migrate")"
        [ "${code}" = 201 ] || { echo "copying ${SEED_REPOSITORY}: HTTP ${code}" >&2; exit 1; }
        echo "copied ${SEED_REPOSITORY} into ops/homelab"
        ;;
    *) echo "checking ops/homelab: unexpected status" >&2; exit 1 ;;
esac
```
